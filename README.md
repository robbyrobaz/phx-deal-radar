# PHX Deal Radar — public board

Static snapshot of a personal flight-deal monitor for Phoenix (PHX): award and
cash prices scraped from aa.com and delta.com, ranked by value (¢/mile),
discount vs each route's own price history, and bookability.

Regenerated every 20 minutes when prices change. Live page: https://robbyrobaz.github.io/phx-deal-radar/
